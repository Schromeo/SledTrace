# 给下一位助手的交接入口

本文件只维护导航与工作约定，不维护版本、阶段进度或测试历史。

## 默认阅读路径

小任务只读 AGENTS.md 和要改的文件；以下顺序用于接手阶段或选择下一步。

1. 根目录 AGENTS.md：长期规则、授权边界和验证。
2. [CURRENT_TASK](CURRENT_TASK.md)：本片、父里程碑出口、预算与下一决策。
3. [AI_HANDOFF](AI_HANDOFF.md)：当前实现、缺口与代码入口。
4. [ROADMAP](ROADMAP.md)：阶段状态和候选顺序。

选阶段或改变方向时，再读 [详细计划](../product/ROAD_TO_V1_0.md) 的相关章节。
需要重要选择理由时查 [DECISIONS](DECISIONS.md)；需要旧命令/失败时查
[DEVLOG](DEVLOG.md)。日期快照只在追溯历史时读，不作为执行授权。

## 不要重复犯的错误

- 中文回复；以当前代码和已标注来源的证据为准，不附和旧模型的乐观结论。
- 先比较能否复用现有证据，再提出采集、契约或基础设施扩张。
- 切片完成不等于里程碑完成；换片号不重置父目标、预算或未知投入。
- 测试/截图证明工程行为，不证明真实质量、根因、节省或外部采用。
- 通过写定验收立即停；证据不足可以归档/收窄，不无限追随机失败。
- 收尾：DEVLOG 写一条简短证据，CURRENT_TASK 更新本片状态；ROADMAP 等其余
  文件仅在各自职责变化时更新。用户没要求时不写下一片。
- 使用现有 slice/review 流程；不另建管理系统。历史付费额度不是长期授权。
- 用户最新指令优先；提案、普通继续和文档批准都不自动授权跨仓库、
  新公共/存储契约、付费调用、合并或发布。

目标是让人独立、反复做出有用的诊断与修改决定，而不是完成全部名词。
